- [Easing và typography](easing-and-typography.md): Flow, EaseCopy, Ease and Wizz, TextEvo, TextExploder.
- [Render effects](render-effects.md): chọn retime, motion blur, displacement, fill và look theo nhiệm vụ.
- [Script và preset](scripts-and-presets.md): dependency, payload đóng gói, thao tác xóa và giới hạn FFX.
