# Styles — Combining Techniques into Visual Styles

Style guides describe visual characteristics and editorial pacing, then link to the underlying techniques and resources. A single edit can blend multiple styles; these pages provide proposed assembly workflows rather than rigid classifications of entire reference projects.

- [Collage](collage.md): Cutouts, typography, drop shadows, and multi-layered layouts.
- [Dreamy / Atmospheric](dreamy.md): Soft lighting, bokeh, atmospheric overlays, and gentle motion.
- [Retro / VHS](retro-vhs.md): Analog textures, scanlines/noise, and deliberate stepped timing.
- [Impact](impact.md): Action accents driven by timing, camera shake, flash/warp transitions, and sound design.

No universal preset pack or canonical preview render is assumed for any style. [Back to Library](../README.md).
