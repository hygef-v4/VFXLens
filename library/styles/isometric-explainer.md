# Isometric Explainer — AI-Assisted Motion Graphics

## Classification

| Axis | Classification |
| --- | --- |
| Video family | Motion graphics |
| Communication format | Explainer / editorial infographic |
| Visual style | Isometric illustration with 2D or 2.5D composition |
| Proposed production method | AI-assisted, code-driven graphics and animation |

**AI-assisted motion graphics** describes how this repo will produce the work: an agent develops the script, scene data, assets/code, animation and renders. The visual category remains motion graphics. Record generated images, generated speech, external documentary assets and procedural graphics separately in each production's asset inventory.

The [Internet Global Explainer case study](../case-studies/internet-global-explainer.md) supports the visual classification. Its original production software and extent of AI involvement remain unverified; a proposed AI pipeline is not recovered production metadata.

## Defining Characteristics

- A consistent isometric viewpoint, outlined props, platform thickness and restrained shadows give spatial structure to simplified illustrations.
- Short labels, evidence/claim cards, source footers, status stamps, diagrams and timelines carry the explanation.
- Reused props and a recurring recap board preserve continuity between chapters. Palette changes help mark groups of ideas.
- Objects and connections appear in explanatory order. An entrance lands, holds long enough to read, then changes state or exits.
- Uncertainty is visible: allegations, responses, missing evidence and confirmed observations receive distinct labels. Decorative motion does not replace the underlying explanation.

An isometric appearance can be built from 2D shapes. Use real 3D when changes in camera angle, occlusion or lighting require it; do not infer a 3D scene from a fixed isometric image alone.

## Production Route

Follow the [AI-assisted motion-graphics workflow](../../workflows/ai-assisted-motion-graphics.md) alongside the shared [production workflow](../../workflows/create-video.md). The specialized workflow owns the stage order, tool choices and completion criteria; this page owns the visual classification and inspection criteria.

Build a small reusable vocabulary: platform/prop, entity label, claim card, source footer, status stamp, timeline and recap board. Prefer configurable states of a component to a separate custom scene for every sentence.

## Inspection Criteria and Pitfalls

- Check a stable projection, coherent stroke/shadow treatment, text size, diacritics in the script's language, source visibility and spacing between labels and props.
- Verify changes in reading order against narration. Keep a readable hold after a fast entrance and inspect at the intended viewing size.
- Treat classification/status as data, not a color-only decoration. Missing values are not zero; uncertain attribution is not a confirmed cause.
- Generated illustrations or reconstructed UI must be identifiable as illustration. Preserve authentic source material when a shot claims to show a document or screenshot.
- Sample long references across their full duration, then inspect selected transitions densely. Report selected-window coverage separately from full-source coverage.
- Use the source's measured timings as evidence, then record the new film's timing decisions. Do not inherit its dimensions, duration, mastering levels or a particular effect's frame count automatically.
