# Example invocations

Codex uses `$motion-scout`; Claude Code can use `/motion-scout`. Both discovery
paths load the same canonical instructions and support explicit research/build mode.

**Research only, current technology:**

> Use $motion-scout in research-only mode. Find exceptional and recently trending
> open-source Three.js, WebGPU and Remotion projects for a cinematic sci-fi product
> commercial. Search GitHub and accessible X sources across 7/30/90 days and
> established work, inspect code/visuals/licenses, rank candidates and propose an
> integration plan. Do not install anything.

**Reference-led discovery:**

> /motion-scout Find open-source technology for a character explainer with deep,
> layered lighting and a camera like the reference video. Check components already
> in the project and current sources online; separate strong technique from virality.
> Research only; state what was not viewed or run.

**Authorized build with a bounded handoff:**

> Use $motion-scout to research and build a 12-second horizontal product reveal
> in the existing VFXLens studio. Reuse compatible local code, select only needed
> additions, hand the evidence to remotion-3d-director, render and inspect the MP4.
> Keep paid services and large model downloads disabled.

These prompts specify outcomes, not a fixed repository catalog. The actual sources
and technology choice must come from the current brief, local inventory and live
research results.
