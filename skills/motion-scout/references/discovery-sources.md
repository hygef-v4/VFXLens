# Live discovery strategy

Turn the brief into visual jobs and implementation constraints before searching:
for a sci-fi commercial, jobs might include a product reveal, emissive surface,
analytical particle morph, camera move and readable typography. Search those jobs,
not only the name of the current framework.

Use two lanes: community attention and exceptional implementation. A small,
well-documented effect can outrank a popular framework. Balance new/active work,
established foundations, hidden gems and reusable local components.

| Source | What it can establish | What still needs inspection |
| --- | --- | --- |
| GitHub MCP/API | Repo metadata, files, commit/version, maintenance signals | Visual quality, safe execution and actual video compatibility |
| Native web search/fetch | Current discovery, official links, indexed posts | Search snippets/date labels are leads; open primary sources |
| Authorized/public X | Original demonstration/announcement and visible dated metrics | Code, license, accessibility and historical growth |
| Official docs/demo sites | API semantics, examples, visual output | Exact installed-version fit and arbitrary-frame behavior |
| npm/component registries | Package/version and component install contracts | Per-item dependencies, install scripts and licenses |
| GitHub Trending/discovery sites | Dated attention leads | Window semantics, original repo and reliable star history |

Query families, adapted to the task and current dates:

- GitHub: `webgpu particles`, `threejs cinematic`, `remotion product`, TSL morphs,
  R3F shader/scene templates and domain-specific procedural geometry.
- Skills/tools: relevant renderer + `SKILL.md`, agent skills, creative MCP,
  CLI/editor automation. Inspect skill text without executing it.
- Hidden gems: narrow effect terms, modest star ranges, new authors, example
  implementations and official ecosystem showcases rather than star sorting alone.
- Reference lane: unusual WebGL experiments, motion breakdowns and polished
  interactions, retaining their status as adaptable references rather than films.

For attention research, derive cutoffs for the last 7, 30 and 90 days and log the
UTC interval. `created:` finds new repos; `pushed:` finds code activity. Neither
measures stars gained. Record these search scopes separately from verified star
history. Established projects need no new-release claim to be exceptional.

Deduplicate canonical owner/repo URLs and renamed/forked/repackaged equivalents;
keep distinct implementations when their tradeoffs matter. Prefer 5–15 relevant
candidates when enough accessible evidence exists. Explain shortfalls instead of
padding the list. Open implementation files and actual demo media for finalists;
stop inspecting candidates whose license or basic architecture already rules out
the proposed use.
